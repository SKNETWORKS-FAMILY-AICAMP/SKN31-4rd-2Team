## 2. 공통 레이아웃

### 2-1. base.html

로그인 후 모든 페이지가 상속하는 기본 레이아웃입니다. 아래 화면 3~11의 이미지 상단에 공통으로 보이는 네비게이션 바가 여기서 정의됩니다(홈 화면 기능정의표 ①번 참고).

| 요소 | 설명 |
|------|------|
| 프로필 드롭다운 | `#profile-menu-toggle` 클릭 → `#profile-dropdown` 표시, 바깥 클릭/Esc로 닫힘 (`common.js: initProfileMenu()`) |
| 토스트 알림 | Django `messages` 연동, **2초 후 자동 사라짐** + 닫기 버튼 (`common.js: initToasts()`) |

블록 목록: `title`, `nav_home_active`, `nav_chatbot_active`, `nav_records_active`, `nav_board_active`, `extra_css`, `content`, `extra_js`

### 2-2. base_auth.html

로그인/회원가입 전용 레이아웃. 로고+타이틀+서브타이틀 + `content` 블록으로 구성됩니다.

### 2-3. common.js 유틸리티 요약

| 함수 | 대상 선택자 | 실제 사용 여부 |
|------|-------------|----------------|
| `initToasts()` | `[data-toast]` | ✅ base.html 토스트에서 사용 |
| `initProfileMenu()` | `#profile-menu-toggle` | ✅ base.html 프로필 메뉴에서 사용 |

## 3. 로그인 (login.html)

**상속**: base_auth.html · **URL name**: `account:login`

**기능 정의**

| 번호 | 항목 | 설명 | 이벤트/비고 |
|------|------|------|--------------|
| 1 | 로그인 / 회원가입 탭 | 로그인 화면과 회원가입 화면을 전환하는 탭 메뉴 | 클릭 시 해당 URL로 이동(단순 링크, JS 없음) |
| 2 | 아이디 입력 | 사용자 계정 아이디를 입력하는 텍스트 필드 | 포커스 시 테두리 강조, 값 미입력 시 제출 불가 |
| 3 | 비밀번호 입력 | 비밀번호를 입력하는 텍스트 필드(마스킹 처리) | 포커스 시 테두리 강조, 값 미입력 시 제출 불가 |
| 4 | 로그인 버튼 | 입력한 아이디/비밀번호로 로그인 요청 전송 | 클릭 시 POST 제출 → 실패 시 상단에 `form.non_field_errors` 표시 |

**폼 필드**: `username`(text), `password`(password), `next`(hidden, 로그인 후 리다이렉트 경로)

## 4. 회원가입 (signup.html)

**상속**: base_auth.html · **URL name**: `account:signup`

**기능 정의**

| 번호 | 항목 | 설명 | 이벤트/비고 |
|------|------|------|--------------|
| 1 | 로그인 / 회원가입 탭 | 두 화면을 전환하는 탭 메뉴 | 클릭 시 해당 URL로 이동 |
| 2 | 기본 정보 입력 | 아이디/이메일/비밀번호/비밀번호 확인/입대일 입력 필드 | 값 미입력 또는 형식 오류 시 필드별 에러 메시지 표시 |
| 3 | 신분 선택 | 병사 / 간부 중 하나를 선택하는 카드형 라디오 | 선택 시 아래 계급 목록과 마스코트 문구가 즉시 전환됨 |
| 4 | 마스코트 안내 문구 | 신분에 따라 반말/존댓말 톤이 바뀌는 안내 멘트 | 병사="야, 형이 다 알려줄게!" / 간부="답변드리겠습니다." |
| 5 | 계급 선택 | 신분이 병사면 병사 계급, 간부면 장교/부사관 그룹 계급 목록으로 전환 | 신분 선택값에 따라 다른 choices 렌더링 |
| 6 | 가입 완료 버튼 | 입력값 검증 후 회원가입 요청 제출 | 클릭 시 POST 제출 → 성공 시 로그인 화면 또는 홈으로 이동 |

**폼 필드**: `username`, `email`, `password1`/`password2`, `enlist_date`(date), `status`(radio: 병사/간부), `rank`(radio, 병사 전용), `officer_rank`(그룹 radio, 간부 전용)

**상속**: base.html · **URL name**: `chatbot:chat` · **JS**: chat.html 인라인 스크립트

**기능 정의**

| 번호 | 항목 | 설명 | 이벤트/비고 |
|------|------|------|--------------|

| 3 | 대화 목록 항목 | 과거 대화 제목/미리보기/삭제(✕) 버튼(반복) | 항목 클릭 시 해당 대화 로드, ✕ 클릭 시 confirm 후 삭제 |

| 4 | 게시글 카드 | 카테고리/제목/요약/좋아요·조회·댓글 수를 보여주는 카드(반복) | 카드 클릭 시 `board:detail` 상세 화면으로 이동 |


**기타**: `board.js`의 `pageshow` 이벤트로, 뒤로가기 진입 시 캐시 대신 강제 새로고침되어 최신 데이터를 보여줍니다(게시판 화면 공통 적용).

## 9. 게시글 상세 (post_detail.html)

**상속**: base.html · **URL name**: `board:detail` · **JS**: `board/js/board.js`
