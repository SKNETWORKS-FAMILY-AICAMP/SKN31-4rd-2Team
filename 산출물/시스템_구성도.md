# 시스템 구성도

본 시스템은 AWS EC2 기반의 단일 서버 환경에서 구축하였으며, 사용자의 HTTP 요청은 Nginx와 Gunicorn을 거쳐 Django Web Application에서 처리되도록 구성하였습니다.

챗봇 서비스는 OpenAI API와 Neo4j Aura, Qdrant를 연동한 하이브리드 RAG 구조를 적용하였습니다. 군 관련 법령 정보는 Neo4j Aura를 통해 검색하고, 병영생활 문서는 Qdrant를 활용하여 의미 기반 검색을 수행하도록 구성하였습니다.

또한 회원 정보, 게시글, 대화 내역 및 개인 기록 데이터는 AWS RDS(MySQL)에 저장 및 관리하도록 설계하였습니다. 아래 그림은 시스템의 주요 구성 요소와 데이터 흐름을 나타낸 시스템 구성도입니다.
