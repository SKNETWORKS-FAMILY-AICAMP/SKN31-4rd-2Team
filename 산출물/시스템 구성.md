# 🏗️ 시스템 구성도

본 시스템은 AWS EC2 환경에서 Django 기반 웹 애플리케이션을 운영하며, Nginx와 Gunicorn을 통해 사용자 요청을 처리합니다.

AI 챗봇은 OpenAI API와 Neo4j Aura, Qdrant(Vector DB)를 연동한 하이브리드 RAG 구조로 동작하며, 회원 정보와 게시글, 대화 내역 및 개인 기록은 AWS RDS(MySQL)에 저장됩니다.
