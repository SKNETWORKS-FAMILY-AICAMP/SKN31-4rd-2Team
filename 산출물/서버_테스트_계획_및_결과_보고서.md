## 1. 문서 개요

### 1.1 목적
본 문서는 요구사항 정의서에서 정의한 요구사항 및 추적성 매트릭스를 기준으로, 테스트 범위·시나리오·기대 결과를 사전 정의한 계획과, 이를 실제 환경에서 실행한 결과를 하나의 문서로 통합하여 요구사항-화면설계-개발-테스트 간 추적성을 확보하는 것을 목적으로 한다.

### 1.2 테스트 범위
사용자 화면(회원가입/로그인, 홈 대시보드, 챗봇, 개인기록, 익명 커뮤니티 게시판) 및 마이페이지 등 애플리케이션의 전반적인 핵심 기능과 E2E 자동화 테스트를 포함한다.

### 1.3 테스트 환경

| 항목 | 내용 |
|---|---|
| 백엔드 | Python 3.13, Django (MVT), MySQL |
| 프론트엔드 | Django Template (HTML/CSS/JS) |
| 자동화 도구 | Playwright |
| 실행 대상 |  E2E 테스트 환경 |
| 실제 실행일 | 2026-08-07 |

### 1.4 테스트 전략
- 요구사항 정의서 6장 추적성 매트릭스의 TC ID 체계를 그대로 준용하여 FR/NFR/LLM 요구사항과 1:1 매핑되도록 테스트케이스를 구성한다.
- 인증, 폼 검증, CRUD 등 핵심 기능은 Playwright 기반의 E2E 자동화 테스트 코드로 구현하여 반복 및 회귀 테스트가 가능하게 한다.
- UI 조작 및 상태 변화(게시글 작성, 조회수 변화, 챗봇 응답 등)는 실제 브라우저 렌더링 결과를 기준으로 검증한다.
- 발견된 이슈는 증상-원인-수정-재검증의 흐름으로 추적 가능하게 기록한다.

## 3. 코드 리뷰 중 확인이 필요했던 사항 (팀 확인 결과: 이슈 아님)

아래 항목들은 테스트 코드 작성을 위해 `views.py`/`*.js`를 리뷰하던 중 "요구사항과 다르게 동작하는 것처럼 보여서" 한 번 짚고 넘어갔던 것들입니다. 팀 확인 결과 전부 **의도된 동작**으로 확인되어, 위 표의 `기대 결과`를 실제 의도에 맞게 수정했습니다. (버그가 아니므로 회고/기록 목적으로만 남겨둡니다.)

### 확인-001: 게시글 조회수는 새로고침 시에도 계속 증가함 → 의도된 동작
- **관련 TC**: TC-BRD-03
- **위치**: `board/views.py` → `post_detail`
- **처음 의문이 든 이유**: 함수 docstring에는 "새로고침 시 조회수가 중복으로 올라가는 것을 방지"한다고 적혀 있는데, 실제 코드는 세션/쿠키 체크 없이 매 요청마다 무조건 `view_count += 1`을 실행함.
- **팀 확인 결과 (2026-08-07)**: 무조건 증가가 맞는 설계. docstring 문구가 실제 동작과 다르게 남아있는 것뿐이므로, 담당 팀원이 시간 될 때 docstring만 정리하면 좋을 것 같습니다.

### 확인-002: 챗봇 출처가 별도 UI 없이 답변 본문에 포함됨 → 의도된 동작
- **관련 TC**: TC-CHAT-02
- **위치**: `chatbot/views.py` → `chat_stream`, `chatbot.js` → `loadConversation`
- **처음 의문이 든 이유**: SSE `done` 이벤트와 대화 내역 조회 응답에 `references` 필드가 있는데도 화면에 이를 표시하는 별도 UI 코드가 없어서, "출처가 아예 안 보이는 것 아닌가" 하고 의심했습니다.
- **팀 확인 결과 (2026-08-07)**: 챗봇 시스템 프롬프트에서 답변 본문 마지막에 출처를 포함하도록 지시하고 있어서, 별도 UI 없이도 답변 텍스트 자체에 출처가 포함됨. `Message.references` 필드가 실제로 화면에 쓰이지 않는 값이라면(중복/미사용), 정리가 필요한지 정도만 담당 팀원이 검토하면 좋을 것 같습니다.

### 확인-003: FAQ 버튼도 매번 AI 스트리밍을 호출함 → 의도된 동작
- **관련 TC**: TC-CHAT-04
- **위치**: `chatbot.js` (FAQ 클릭 핸들러), `chatbot/urls.py`
- **처음 의문이 든 이유**: FAQ 전용 즉답 엔드포인트가 urls.py에 없고, FAQ 버튼이 일반 채팅 입력과 동일한 `sendMessage()`를 그대로 호출하고 있어서, "즉답이 아니라 매번 AI를 다시 호출하는 것 아닌가" 하고 의심했습니다.
- **팀 확인 결과 (2026-08-07)**: FAQ는 질문을 빠르게 선택해주는 용도이고, 답변 자체는 일반 채팅과 동일하게 AI 스트리밍으로 처리되는 게 맞는 설계.

### 확인-004: 홈 화면에 개인기록 요약 / 인기 게시글 랭킹 섹션이 없음 → 의도된 동작
- **관련 TC**: TC-HOME-01
- **위치**: `home/index.html`
- **처음 의문이 든 이유**: testcase.md의 원래 기대 결과에는 "최근 작성한 개인기록 요약"과 "커뮤니티 인기 게시글 랭킹"이 명시되어 있는데, 실제 템플릿에는 D-Day 카드와 서비스 안내 카드(단순 바로가기 링크) 3개, 긴급신고 배너만 있고 데이터 요약 섹션은 없음.
- **팀 확인 결과 (2026-08-07)**: 두 섹션은 기획상 없는 것이 맞음.
