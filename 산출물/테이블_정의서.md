# 테이블 정의서

> `military_life/*/models.py`에 정의된 Django 모델을 기준으로 작성한 테이블 정의서입니다.
> DB는 MySQL(mysqlclient)이며, 테이블/컬럼명은 Django ORM이 실제로 생성하는 이름(`앱이름_모델명`, 소문자 snake_case)을 기준으로 표기했습니다.
> `AUTH_USER`는 Django 기본 사용자 모델(`django.contrib.auth.models.User`)이며, 나머지 테이블은 모두 이 테이블을 참조합니다.

---

## 테이블 목록

| 앱 | 테이블명 | 설명 |
|----|---------|------|
| auth (Django 기본) | auth_user | 회원(사용자) 계정 정보 |
| account | account_profile | 회원 부가 정보(신분/계급/복무기간) |
| board | board_category | 게시판 카테고리 |
| board | board_post | 게시글 |
| board | board_comment | 댓글 |
| board | board_postlike | 게시글 좋아요 |
| board | board_report | 게시글 신고 |
| chatbot | chatbot_conversation | 챗봇 대화방 |
| chatbot | chatbot_message | 챗봇 대화 메시지 |
| chatbot | chatbot_chattopic | 챗봇 FAQ 주제(카테고리) |
| chatbot | chatbot_faq | 챗봇 FAQ 질문 |
| records | records_journalentry | 개인기록 캘린더 일지 |
| records | records_goal | 개인기록 목표 |
| records | records_bookmark | 챗봇 답변 북마크 |

# auth_user 테이블 정의서

## 기본 정보
- **테이블 이름**: auth_user
- **테이블 설명**: Django 기본 인증 모델. 회원가입/로그인에 사용되는 계정 정보를 저장

## 컬럼 정보
| 컬럼명 | 데이터 타입 | 길이 | NULL 허용 | 기본값 | 설명 |
|--------|------------|------|-----------|--------|------|
| id | INT | - | NN | AUTO_INCREMENT | 사용자 고유 식별자 |
| username | VARCHAR | 150 | NN | - | 로그인 아이디 (UNIQUE) |
| password | VARCHAR | 128 | NN | - | 암호화된 비밀번호 |
| email | VARCHAR | 254 | Y | '' | 이메일 (회원가입 화면 반영) |
| is_staff | BOOL | - | NN | 0 | 관리자 사이트 접근 여부 |
| is_active | BOOL | - | NN | 1 | 계정 활성화 여부 |
| is_superuser | BOOL | - | NN | 0 | 최고 관리자 여부 |
| date_joined | DATETIME | - | NN | CURRENT_TIMESTAMP | 가입 일시 |
| last_login | DATETIME | - | Y | NULL | 마지막 로그인 일시 |

## 제약 조건
| 제약 조건 | 설명 |
|-----------|------|
| PRIMARY KEY | id에 대한 기본 키 제약 조건 |
| UNIQUE | username에 대한 유일 제약 조건 (중복 아이디 가입 방지) |

## 인덱스
| 인덱스 | 컬럼 | 설명 |
|--------|------|------|
| IDX_AUTH_USER_USERNAME | username | 로그인 시 아이디 조회용 인덱스 |

## 기타 정보
| 항목 | 내용 |
|------|------|
| 관리 주체 | Django 내장(`django.contrib.auth`), 마이그레이션으로 자동 생성 |
| 비고 | 회원 탈퇴 시 계정 row 자체가 삭제됨(`delete_account_view`) |

# account_profile 테이블 정의서

## 기본 정보
- **테이블 이름**: account_profile
- **테이블 설명**: 회원의 군 복무 관련 부가 정보(신분/계급/입대일/전역일)를 저장하는 테이블

## 컬럼 정보
| 컬럼명 | 데이터 타입 | 길이 | NULL 허용 | 기본값 | 설명 |
|--------|------------|------|-----------|--------|------|
| id | INT | - | NN | AUTO_INCREMENT | 프로필 고유 식별자 |
| user_id | INT | - | NN | - | 연결된 회원 ID (auth_user 참조, UNIQUE) |
| status | VARCHAR | 10 | NN | '병사' | 신분("병사" / "간부") |
| rank | VARCHAR | 20 | NN | - | 계급 |
| enlist_date | DATE | - | NN | - | 입대일 |
| discharge_date | DATE | - | NN | - | 전역(예정)일 |

## 제약 조건
| 제약 조건 | 설명 |
|-----------|------|
| PRIMARY KEY | id에 대한 기본 키 제약 조건 |
| UNIQUE | user_id에 대한 유일 제약 조건 (회원 1명당 프로필 1개, OneToOne) |
| FOREIGN KEY | user_id에 대한 외래 키 제약 조건 (auth_user 테이블 참조) |

## 인덱스
| 인덱스 | 컬럼 | 설명 |
|--------|------|------|
| IDX_PROFILE_USER | user_id | user_id 컬럼에 대한 인덱스 |

## 기타 정보
| 항목 | 내용 |
|------|------|
| 비고 | discharge_date는 신분(병사/간부)별 복무기간 상수를 기준으로 서버에서 계산되어 저장됨 |

## 외래 키 정보
| 항목 | 내용 |
|------|------|
| 참조 테이블 | auth_user |
| 참조 컬럼 | id |
| 연관 컬럼 | user_id |
| ON DELETE | CASCADE |
| ON UPDATE | CASCADE |

# chatbot_conversation 테이블 정의서

## 기본 정보
- **테이블 이름**: chatbot_conversation

| id | CHAR | 32 (UUID) | NN | uuid4() | 대화방 고유 식별자 |
| user_id | INT | - | Y | NULL | 대화 소유 사용자 ID (auth_user 참조) |
| title | VARCHAR | 255 | Y | '' | 대화방 제목(사이드바 표시용) |
| created_at | DATETIME | - | NN | CURRENT_TIMESTAMP | 대화방 생성 시각 |
| updated_at | DATETIME | - | NN | CURRENT_TIMESTAMP | 마지막 메시지 갱신 시각 |

## 제약 조건
| 제약 조건 | 설명 |
|-----------|------|
| PRIMARY KEY | id(UUID)에 대한 기본 키 제약 조건 |
| FOREIGN KEY | user_id에 대한 외래 키 제약 조건 (auth_user 테이블 참조) |

## 인덱스
| 인덱스 | 컬럼 | 설명 |
|--------|------|------|
| IDX_CONVERSATION_USER | user_id | user_id 컬럼에 대한 인덱스 |

## 기타 정보
| 항목 | 내용 |
|------|------|
| 정렬 기준 | updated_at 내림차순 (사이드바 "최근 대화" 목록) |

## 외래 키 정보
| 항목 | 내용 |
|------|------|
| 참조 테이블 | auth_user |
| 연관 컬럼 | user_id |
