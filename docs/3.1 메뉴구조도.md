# military_life 메뉴구조도 (Menu Structure)

> `military_life/*/urls.py`에 정의된 실제 라우팅과 `화면설계서.md`를 기준으로 작성한 메뉴 구조도입니다.
> 레벨 1~4 단계로 정리하였으며, 비로그인 사용자는 [인증] 메뉴만 접근 가능하고 그 외 메뉴는 로그인이 필요합니다(`@login_required`).
